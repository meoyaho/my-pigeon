# 데스크톱 비둘기 펫 — 설계 문서

날짜: 2026-08-04

## 개요

데스크톱 화면 위를 돌아다니는 비둘기 펫 앱. 앱을 실행하면 비둘기가 "출근"해 화면 위에서 다양한 인터랙션을 하다가, 사용자가 트레이 메뉴에서 "퇴근"을 누르면 인사를 남기고 사라지며 앱이 종료된다.

## 1. 아키텍처

- **Electron** 기반 크로스플랫폼(Mac/Windows) 데스크톱 앱
- **메인 프로세스**
  - 시스템 트레이 아이콘 및 메뉴(먹이 주기 / 사진 찍기 / 퇴근) 관리
  - 포커스 창 전환 감지(`active-win` 라이브러리, 1~2초 폴링)
  - IP 기반 대략적 위치 조회 → 날씨 조회 (Open-Meteo API, API 키 불필요), 시작 시 1회 + 이후 30분 주기 갱신
  - 카메라 촬영 시 별도의 작은 BrowserWindow 생성/관리
  - "퇴근" 처리(렌더러에 퇴장 신호 전달 → 애니메이션 완료 대기 → 앱 종료)
- **렌더러 프로세스**
  - 투명·프레임리스·always-on-top 풀스크린 오버레이 창 1개
  - **PixiJS**로 픽셀아트 스프라이트 렌더링 및 게임 루프(움직임/애니메이션/FSM/그룹 로직) 실행
  - 기본적으로 클릭 통과(다른 앱 조작 방해 없음). 비둘기 히트박스 위에 커서가 있을 때만 해당 영역 클릭 가능하도록 동적 전환 (`setIgnoreMouseEvents` + 히트테스트). 먹이 배치 모드 중에는 화면 전체 클릭 가능.
- 사운드 요소 없음 (v1 스코프 제외)

## 2. 비둘기 상태 & 행동 시스템 (FSM)

각 비둘기는 유한상태기계로 동작한다.

| 상태 | 설명 |
|---|---|
| Idle/Walking | 화면을 어슬렁거리며 걷기 |
| WeirdBehavior | 랜덤 타이머로 주기적 발동. 5종 중 랜덤 선택: 발라당 뒤집기 / 머리에 깃털 꽂기 / 한 다리로 졸기 / 구애 구구거리기 / 폴짝폴짝 뛰기 |
| FlyingToFood / Eating | 먹이 지점으로 이동 후 자리다툼(밀치기) 미니 애니메이션과 함께 취식 |
| Scattering | 마우스 훠이훠이 동작 감지 시 반경 내 비둘기가 사방으로 흩어짐 |
| Startled | 포커스 창 전환 감지 시 화면 위로 날아올랐다 화면 가장자리에 잠깐 붙어 두리번거린 후 복귀 |
| WeatherReaction | 비/눈 감지 시 화면 구석에 웅크림, 갠 후 몸 털기 |
| Dragged | 사용자가 클릭 드래그하면 손에 들려 이동, 놓으면 착지 |
| CommuteIn | 앱 실행 시 화면 밖에서 날아 들어와 착지, 출근 멘트 말풍선 표시 후 Idle 진입 |
| CommuteOut | 트레이 "퇴근" 클릭 시 퇴근 멘트 말풍선 표시 후 화면 밖으로 퇴장 |

평소엔 메인 비둘기 1마리만 존재. 먹이 상호작용 시에만 임시 비둘기(TemporaryPigeon) 최대 8마리가 풀(pool)로 스폰되고, 상호작용 종료(소진 타이머 만료 또는 전원 흩어짐) 시 정리되어 사라진다.

## 3. 데이터 흐름 & 상호작용 상세

### 먹이 주기 (위치 지정)
1. 트레이 "먹이 주기" 클릭 → 오버레이가 "먹이 배치 모드" 진입 (커서가 먹이 아이콘으로 변경, 이 모드 동안 화면 전체 클릭 가능)
2. 사용자가 화면 아무 지점 클릭 → 해당 좌표에 먹이 스폰
3. 메인 비둘기가 즉시 해당 좌표로 `FlyingToFood` 진입
4. 임시 비둘기 8마리가 0.3~1초 간격으로 화면 밖 랜덤 지점에서 좌표 주변으로 순차 스폰
5. 전원 도착 후 Eating 루프(자리다툼 애니메이션 포함)
6. 먹이 소진 타이머 종료 시 순차적으로 화면 밖으로 흩어져 퇴장, 메인 비둘기만 잔류
7. 배치 모드 진입 후 5초 내 클릭이 없으면 자동 취소, 클릭 통과 모드로 복귀

### 훠이훠이 (쫓기)
- 렌더러가 mousemove 이벤트의 속도/방향 벡터를 추적, 임계값 이상이면 반경 내 모든 비둘기가 Scattering 진입 (마우스 반대 방향으로 짧게 도망친 뒤 Idle 복귀)

### 드래그 이동
- mousedown이 비둘기 히트박스 위에서 시작되면 Dragged 진입, mouseup 시 그 위치에 착지

### 포커스 창 전환
- 메인 프로세스가 `active-win` 폴링으로 변화 감지 → IPC로 렌더러에 알림 → 화면 내 비둘기 중 확률적으로 일부만 Startled 진입 (매번 전부 반응하면 산만하므로)

### 날씨
- 메인 프로세스가 시작 시 + 30분 주기로 IP 위치 조회 → Open-Meteo 호출 → 상태(맑음/비/눈) IPC로 렌더러 전달 → WeatherReaction 상태 반영

### 출퇴근
- **출근(CommuteIn)**: 앱 실행 시 자동 발생. 화면 밖에서 날아 들어와 착지 → 출근 멘트 풀에서 랜덤 문구("오늘도 열심히 해보자고" 류) 말풍선 표시 → Idle 진입
- **퇴근(CommuteOut)**: 트레이 "퇴근" 클릭 시 발생. 퇴근 멘트 풀에서 랜덤 문구("오늘도 수고했어" 류) 말풍선 표시 → 화면 밖으로 퇴장 애니메이션 → 완료 후 앱 프로세스 종료
- 별도의 "종료" 메뉴는 없음. "퇴근"이 유일한 종료 경로.

### 카메라 촬영
- 트레이 "사진 찍기" 클릭 → 작은 별도 BrowserWindow(웹캠 `getUserMedia`) 오픈 → 촬영 버튼 클릭 시 웹캠 프레임 + 현재 비둘기 스프라이트 프레임을 캔버스에 합성 → 파일 저장 다이얼로그로 로컬 저장 (v1은 필터/보정 없이 단순 합성)

## 4. 에러 처리 & 예외 상황

- **날씨 API 실패/오프라인**: 마지막 성공값 유지, 없으면 기본값(맑음)으로 폴백. 다음 주기 호출에서 자동 재시도.
- **IP 위치 조회 실패**: 날씨 기능만 비활성화(WeatherReaction 진입 안 함), 나머지 기능은 정상 동작.
- **카메라 권한 거부**: 촬영 창에 안내 메시지만 표시, 앱 크래시 없이 창 닫기 가능.
- **`active-win` 미지원/권한 미승인**: Startled 상태가 발생하지 않을 뿐, 다른 기능엔 영향 없음.
- **먹이 배치 모드 5초 타임아웃**: 클릭 없으면 자동으로 클릭 통과 모드 복귀.
- **다중 모니터**: 화면 밖 스폰/퇴장 좌표는 포커스된(또는 주) 디스플레이 기준으로 계산, 화면 경계 밖으로 새지 않게 처리.
- **절전모드/PC 잠자기 복귀**: 별도 처리 불필요(고정 스케줄이 없으므로) — CommuteIn/Out은 앱 실행/사용자 클릭에만 반응.

## 5. 테스트 전략

- **단위 테스트**: FSM 상태 전이 로직(Idle→WeirdBehavior→Idle, Feeding 시퀀스, Scatter 트리거 조건 등)을 순수 함수로 분리해 Jest로 검증
- **수동 시각 검증**: 스프라이트 애니메이션·자리다툼·퇴장 연출은 실제 앱 실행 후 직접 확인 (webapp-testing/run 스킬로 앱 구동 후 시나리오별 스크린샷)
- **경계 테스트**: 멀티 모니터, 카메라 권한 거부, 오프라인 상태에서 각각 수동 확인
- **핵심 시나리오 체크리스트**:
  1. 앱 실행 → 출근 멘트와 함께 비둘기 등장
  2. 먹이 주기 클릭 → 배치 모드 → 화면 클릭 → 9마리 집결 → 자리다툼 → 소진 후 흩어짐
  3. 마우스로 빠르게 휘저어 훠이훠이 → 비둘기 흩어짐 확인
  4. 다른 앱 창으로 포커스 전환 → 일부 비둘기 Startled 반응
  5. (날씨 API 목킹) 비/눈 상태 → 웅크림/몸 털기 확인
  6. 비둘기 드래그 이동
  7. 랜덤 이상 행동 5종이 순환하며 발생하는지 장시간 관찰
  8. 사진 찍기 → 웹캠+비둘기 합성 이미지 저장 확인
  9. 트레이 "퇴근" 클릭 → 퇴근 멘트 → 퇴장 애니메이션 → 앱 종료 확인

## v1 스코프 밖 (제외됨)

- 애정도/친밀도 시스템
- 고정 시간대(09~18시) 자동 출퇴근 스케줄
- 사운드 반응 및 전반적 사운드 요소
- 실제 다른 앱 창의 좌표 추적 및 착석
- 자기 그림자 놀람, 투명 벽 부딪히기, 화면 긁기, 숨바꼭질, 모래 목욕, 창 제목 읽기, 알 낳기 이스터에그, 똥 테러 등 나머지 아이디어 목록
