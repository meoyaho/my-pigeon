My Pigeon 개인정보 처리방침

시행일: 2026년 8월 5일

개요

My Pigeon은 Chrome 웹페이지 위에 작은 비둘기 집중 동반자를 표시하는 확장 프로그램입니다. 이 확장 프로그램은 개인 정보나 민감한 사용자 데이터를 수집하거나 외부 서버로 전송하지 않습니다.

저장하는 정보

My Pigeon은 확장 프로그램 상태를 유지하기 위해 다음 값을 Chrome 저장소에 저장할 수 있습니다.

  • 비둘기 표시 또는 숨김 설정
  • 출근 또는 퇴근 상태
  • 25분 집중과 5분 쉬는 시간의 타이머 상태
  • 마지막 비둘기 위치와 애니메이션 상태

수집하지 않는 정보

My Pigeon은 페이지 내용, 방문 기록, 검색어, 입력값, 계정 정보, 위치 정보, 결제 정보, 개인 식별 정보를 수집하지 않습니다.

정보 사용 방식

저장된 값은 비둘기 표시 상태, 출퇴근 상태, 집중 타이머, 페이지 이동 뒤 위치 복원을 제공하는 데만 사용됩니다. 광고, 분석, 추적, 프로파일링 목적으로 사용하지 않습니다.

정보 공유와 전송

My Pigeon은 사용자 데이터를 외부 서버로 전송하지 않으며 제3자에게 판매하거나 공유하지 않습니다. 모든 JavaScript, CSS, 이미지 에셋은 확장 프로그램 패키지 안에 포함되어 있고 원격 코드를 실행하지 않습니다.

권한 사용

storage 권한은 확장 프로그램 설정과 타이머 상태를 Chrome 저장소에 보관하기 위해 사용합니다. 일반 웹페이지 접근은 페이지 위에 비둘기 UI를 표시하고 드래그, 우클릭 메뉴, 모이 주기 상호작용을 처리하기 위해 사용합니다.

문의

문의는 Chrome Web Store 등록 페이지에 표시된 게시자 연락처 이메일을 통해 받습니다.
